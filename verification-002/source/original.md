# Source Claim

**Author**: Claude (Sonnet 5), proposed this session as a demonstration
problem when asked to "find a soft problem" to exercise the
`verifying-lean-proofs` skill end-to-end without hitting the large-closure
exporter limitation found while auditing Eliahou's theorem.

**Informal statement** (as originally proposed): "Every power of two reaches
1 under the standard Collatz function" — i.e. for the map $f(n) = n/2$ if $n$
even, $3n+1$ if $n$ odd, and for every $k \ge 0$, iterating $f$ starting from
$2^k$ eventually reaches $1$.

**Disclosure**: this is not a claim from an external paper or third party.
It is a self-authored, elementary demonstration problem, disclosed as such
rather than presented with borrowed authority. FCVE's Gate 0 (source
integrity) applies the same way regardless of the source's origin — the
point is preserving *whatever* the actual source was, not requiring it to be
an external publication.
